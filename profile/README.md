# Areca Backup - Copies of Folders You Name

Areca Backup is a backup of directories you list, written to a disk or a place you administer. It does not log into accounts you were not given, and it does not decide which files matter. You do.

---

## Product Snapshot

A target is the destination. Read its path before the first run. A wrong folder can mix your files into a place you did not mean, or fill a disk you still need. Sources should start as one small directory, not the whole profile.

Encryption uses a password you must keep. Lose it and the copies stay closed. A simulation or a check tells you the job can read its own archive. A restore of one file to an empty folder tells you the bytes come back. Do both before you add the documents you would hate to lose.

## Highlights

- Sources you name, one folder first
- A target path you read out loud
- Filters so caches are not the whole job
- A check that the archive opens
- A restore of one file to an empty directory
- A password you store outside the PC, if you use one

---

## Live Production

Use it for a project you change, with the target on another disk. Run it once while you watch. Then restore a file you know and open it. If the file is wrong or missing, fix the source list before the job grows.

Do not point the target at the same single disk as the only copy of the files. If that disk dies, the backup dies with it. Do not back up a PC you do not administer.

---

## The File You Open

Pick a small text file in the source, restore it somewhere empty, and compare a sentence with the original. That is the test. A green run without that open is not proof. Keep the originals until the sentence matches. Schedule the job only after that.

---

## Setup Path

Prerequisites: A folder you may copy, a destination on another disk, and a password written down if you encrypt.

1. Install Areca Backup and create a target you can find.
2. Add one small source folder.
3. Run the backup and wait until it finishes.
4. Restore one file to an empty folder and open it.
5. Add larger sources only after that file looks right.

## Who Benefits

Areca Backup fits a project you can name and a spare disk you control. It does not fit a machine that is not yours, a target you have not read, or a plan that deletes the originals because the job completed.

---

## Fixes

The restored file is empty or wrong: the source path was wrong, or the job did not finish. Do not add more folders. The archive will not open: the password does not match. Areca cannot invent a new one. The target is full: you included too much. Edit the filters.
